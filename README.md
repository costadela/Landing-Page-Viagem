# Projeto Viagem 🌎

🔗 **[Acessar o site](https://viagem.vitorcostadela.com)**

Site desenvolvido como projeto de estudo em desenvolvimento web, com foco em **HTML e CSS**.

A página apresenta uma viagem por três países da América do Sul:

* 🇦🇷 Argentina
* 🇺🇾 Uruguai
* 🇨🇱 Chile

## 📌 Sobre o projeto

O site reúne informações, imagens e destaques sobre os três países, utilizando uma estrutura simples de página única.

O projeto foi desenvolvido para praticar conceitos fundamentais de desenvolvimento web, como:

* Estruturação de páginas com HTML
* Estilização com CSS
* Flexbox
* CSS Grid
* Responsividade
* Links externos
* Galeria de imagens
* Animações com CSS
* Media Queries
* Navegação entre seções da página

## 🖥️ Seções

O site possui:

* **Home** — apresentação da viagem e acesso a um vídeo.
* **Sobre os Países** — informações sobre Argentina, Uruguai e Chile.
* **Fotos em Destaque** — galeria com imagens dos países.
* **Galeria** — carrossel horizontal com animação.
* **Contato** — links para GitHub, LinkedIn e e-mail.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 🎯 Objetivo

O objetivo deste projeto é colocar em prática os conhecimentos iniciais de desenvolvimento web e construir uma página responsiva utilizando HTML e CSS.
